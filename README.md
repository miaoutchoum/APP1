# APP1 Project

- **The APP1 project is a project of the Louvain-la-neuve polytechnic school which consists of creating a cable car that allows for larger gifts.**
- **In this context, part of the project is focused on designing a computer model for the module's trajectory.**
- **You guessed it, this repository is the source code of our project.**
